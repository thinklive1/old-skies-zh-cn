# Technobabylon 简中翻译与校对规范

目标：保留赛博朋克悬疑的冷峻氛围，同时让对白像角色自己说的话。

1. 从英文原文直接翻译，结合相邻对白、房间和对话主题，不能用逐词替换生成译文。
2. 台词用自然口语；终端、新闻、调查记录使用符合各自场景的正式语体。不要给角色增加原文没有的情绪、解释或网络梗。
3. 人名、组织名、世界观术语以 TERMS.json 为准。未锁定的译名在 review_notes 中记录，不暗自批量替换。
4. 笑话、讽刺、双关优先保留剧情作用和人物态度；谜题提示、密码、设备编号与数量不得改错。
5. 保留开头的 &数字 语音标记、printf 占位符、@宏@、编码控制字符。方括号 [ 是 AGS 换行标记，逐项核对，禁止直接改成中文括号。
6. 中文使用全角标点。对白少用生硬的“进行”“被给予”“对此”；代词可按汉语习惯省略，但指代必须清楚。
7. 菜单和热点名称尽量简洁。长度风险登记为需画面检查，不能为适配强行删掉谜题信息。
8. 开发者解说保留英文。运行时路径、变量、解析器词典和编辑器占位名必须单独识别，不能作为台词翻译。
9. 状态为 untranslated → translated → reviewed。初译不自动标成 reviewed；第二轮逐条对照英文与上下文，改错后记录校对批次。
10. 只有范围分类完成、所有正式范围文本 reviewed、占位符/语音/字体/构建检查通过，才允许生成正式发行包。开发构建须明确标注不完整。
