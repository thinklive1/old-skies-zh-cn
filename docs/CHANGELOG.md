# 版本记录

## v1.1 — 2026-10-03 首轮审校候选版

以那卡nakami的 v1.0 为基础建立可复现的文本修订项目。新增锁定英文原文与原译、逐条审校状态、修改对照、字体覆盖检查、TRA 往返解析校验、安装器版本与哈希同步，以及候选包/正式包发布门槛。

本轮已完成 19,402 条文本核读，共修订 3,157 条，覆盖主线、支线、档案、邮件、物品描述与界面术语。录音花絮、开发者解说保留 v1.0 原文，已恢复先前改动的 31 条相关文字。例如：

- “谢谢你的时间。” → “谢谢，打扰了。”
- “事情必须如此。” → “只能这样了。”
- “你的成就是重要的。” → “你取得的成就很重要。”
- “你能告诉我关于他的什么？” → “能跟我说说他的情况吗？”
- “我小时候救过她” → “她小时候，我救过她”。已根据相邻剧情核对指代。
- 将通讯情境中的 subvocalization 从“默读”改为“默语通讯”。

准确修订数量以 `reports/qa.json` 为准，逐条差异见 `reports/changes.json`。待审条目不视为本版已经完成的润色。

## v1.0 — 上游版本

原简体中文汉化由 B站up主 那卡nakami制作，包含文本、图片、字体和房间脚本修正。完整原包及其授权材料保存在 `upstream/v1.0/`。本项目不改写上游贡献署名。

### 全量收尾

统一吗啡噬、默语通讯、布列塔尼楼、米克斯、头发习作等译名；修正图片操作中的 Socket（插座）误译与部分否定关系；保留英语词义谜题及语音口令所需英语。技术检查通过：英文键、顺序、配音编号、占位符、换行标记、字体新增字形、TRA 往返解析和非字典区块保持一致。

候选版保留未决语境回查记录。用户负责游戏画面确认，项目侧负责安装检查。技术与安装成功不代表已完成游戏内全流程验收。
