# oath 汉化润色 v1.1.0-rc.1

已完成一轮文本核读，本地安装与文件校验通过。当前是公开预发布候选，游戏画面与完整游玩仍待验收。基于现有 `19-dlc-build_v17x_china_v8` 汉化，仅修订文字及被机翻破坏的文本标记。

## 完成范围

登记并核读 11,547 条中文字符串，修订 6,001 处；其中包括语义修正、口语润色、重复句统一、术语、专名、标点与汉化文本标签修复。未改动的 5,546 条保持原样。原有简繁用字按文本保留，没有进行全局繁简转换。

英文注释通过标签、对白数量、角色顺序重新对齐，有 9,786 条中文具有已确认的英文对应。未确认的行号提示只作为回查线索，不作为正确原文。重复的音乐房间与路线提示合并核读，并将一致的修订应用到各个位置。

修订示例：把‘窗户’恢复为界面里的‘窗口’，把‘手办’的 figure、‘鲈鱼’的 bass、‘黑胶唱片’的 vinyl、‘墨盒’的 ink cartridge 按场景译对。音乐人和平台名称恢复专名；信件连贯润色，保留原作叙述中的重复、停顿与含混。测验故意不公平的数字与答案没有擅自纠正。

## 严格的文本范围

修改只落在 6 个原文件的现有文本字符串范围内。每个文件均核对范围之外的字节完全一致，分支、条件、变量定义、调用、数值、标签、资源路径、字体设置及其他代码保持原样。

文本标记的修复仅包括原汉化误译的 `{/字体}`、`{/颜色}`、`{/尺寸}`、`{size=*0。5}`、`[镇民]`、`[persistent。coins]`，恢复其原有 Ren'Py 写法。插值中的变量名和次数保留；日期的变量顺序只在文字内按中文表达调整。

原程序、引擎、archive.rpa、图像、音乐、字体和存档没有修改。补丁使用 6 个 `.rpy` 文本文件和由游戏自带引擎生成的 6 个对应 `.rpyc` 文本缓存覆盖读取，不重打包原资源包。

## 检查

游戏自带 Ren'Py 8.3.7.25031702 分别加载原文件与润色文件，均成功，语句数量均为 52,590。所有节点类型的数量、分支条件、跳转、调用目标、菜单条件和说话角色签名一致。测试在独立目录运行，并在游戏初始化及存档读取前退出，不是可见画面或完整通关验证。

安装后核对 12 个补丁文件，2,649 个其他原文件哈希一致，真实存档保持原样。记录在 `review/installation.json`；逐条修改见 `review/changes.json`，文字范围验证见 `review/text-only-verification.json`。

正文中文字体覆盖检查通过。原包特殊字体 `cc2.ttf` 不含汉字；现有中文在该字体下的显示问题没有通过更改字体或显示代码处理。其字体文件与设置保留，特殊文字画面仍待用户确认。详见 `review/font-coverage.json`。

## 使用与恢复

到 [Release 页面](https://github.com/thinklive1/old-skies-zh-cn/releases/tag/oath-v1.1.0-rc.1) 下载 `oath_zh_polish_1.1.0-rc.1.zip`，完整解压。GitHub 自动生成的 Source code 压缩包是工程源码，不是可直接安装的补丁。

关闭游戏后，在补丁目录执行（需 Python 3.9+）：

```powershell
python tools/install.py --game "D:\software\steam\steamapps\common\oath" install
```

将路径改为实际游戏目录。安装器先核对已适配的原资源包 SHA-256，再记录原文件的存在/不存在状态，备份后写入固定范围的文本文件。

恢复本次润色前的汉化：关闭游戏后执行

```powershell
python tools/install.py --game "<游戏目录>" rollback "<游戏目录>\_oath_zh_polish_backup\<安装时生成的备份编号>"
```

恢复会删除本补丁新增的文本覆盖文件，重新使用未修改的原资源包；如补丁文件后来被其他人更改，恢复脚本拒绝直接覆盖。请保留游戏目录下的备份清单。

## 工程

`source/` 保存从现有资源包只读提取的原始文件；`catalog.json` 保存中文、原译、英文语境、精确范围及核读状态；`review/batches/` 保存 14 个修订批次；`tools/` 提供文本构建、字形与原生加载检查、安装和回滚。本项目位于 `https://github.com/thinklive1/old-skies-zh-cn` 的 `oath-zh-cn` 独立分支。

游戏及现有汉化素材的相关权利归各自作者。本包不包含原游戏程序、图片、音乐、字体或完整资源包，不另行给这些资源添加开源许可。
